Guía de Ingeniería Web Manifest V3

Cómo Crear una Extensión de Chrome desde Cero

Manual técnico completo inspirado en la arquitectura real de GemiMd v1.2: DOM Parsing, Background Service Workers, Almacenamiento Local y REST API Integration.

🧩 1. La Arquitectura Triangular de Manifest V3

Una extensión moderna de Chrome se compone de tres capas aisladas que se comunican mediante mensajes asíncronos:

📄 Content Script

Se ejecuta directamente sobre las páginas web (Gemini, ChatGPT). Tiene acceso al DOM de la página para scrapear o modificar la interfaz.

⚙️ Service Worker

El cerebro en segundo plano. Escucha eventos, realiza peticiones HTTP/REST API externas y maneja la lógica de descargas.

🎨 Popup UI

La ventana emergente interactiva que se abre al hacer clic en el icono. Permite al usuario ajustar opciones y disparar acciones.

📜 2. El Manifiesto (`manifest.json`)

El archivo manifest.json es la carta de identidad de la extensión ante el navegador Chrome:

{
  "manifest_version": 3,
  "name": "Mi Extension Pro",
  "version": "1.0.0",
  "permissions": ["storage", "activeTab", "scripting"],
  
  // CRÍTICO: Permitir peticiones fetch a IP local y servidores externos
  "host_permissions": [
    "http://127.0.0.1/*",
    "https://gemini.google.com/*"
  ],

  "background": {
    "service_worker": "background.js"
  },

  "action": {
    "default_popup": "popup.html",
    "default_icon": {
      "16": "assets/icon-16.png",
      "48": "assets/icon-48.png"
    }
  }
}

💬 3. Comunicación mediante Mensajes (`chrome.runtime`)

Como las capas están aisladas por seguridad, se comunican usando el protocolo de mensajes de Chrome:

1. Enviar desde Popup / Content Script hacia Background:

// popup.js
chrome.runtime.sendMessage({
  action: 'GUARDAR_NOTA',
  data: { titulo: 'Mi Nota', contenido: 'Texto...' }
}, (response) => {
  if (response.success) {
    console.log('Guardado con éxito!');
  }
});

2. Recibir en Service Worker (`background.js`):

// background.js
chrome.runtime.onMessage.addListener((request, sender, sendResponse) => {
  if (request.action === 'GUARDAR_NOTA') {
    fetch('http://127.0.0.1:27123/vault/Nota.md', {
      method: 'PUT',
      body: request.data.contenido
    })
    .then(() => sendResponse({ success: true }))
    .catch(err => sendResponse({ success: false, error: err.message }));

    return true; // OBLIGATORIO para respuestas asíncronas
  }
});

⚡ 4. Trampas Frecuentes y Lecciones de Ingeniería

⚠️ Trampa #1 - Iconos Descalibrados: Si usas imágenes de 400KB (1024x1024) para icon-16.png, Chrome fallará en silencio y mostrará la pieza azul genérica. Redimensiona siempre los PNGs exactamente a 16x16, 32x32, 48x48 y 128x128 px.
⚠️ Trampa #2 - CORS en Manifest V3: Si tu Service Worker hace peticiones fetch() a un puerto local (`http://127.0.0.1:27123`), debes agregar explícitamente "http://127.0.0.1/*" dentro de host_permissions en manifest.json.
