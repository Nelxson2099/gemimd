GemiMd Exporter & Auto-Sync

Manual definitivo paso a paso para convertir, exportar y sincronizar tus conversaciones de Gemini, ChatGPT, Claude y DeepSeek en notas Markdown (.md) atómicas dentro de Obsidian.

📌 1. Introducción y Filosofía

GemiMd nace para resolver la amnesia conversacional de los modelos de lenguaje. Cada diálogo con una Inteligencia Artificial contiene fragmentos valiosos de aprendizaje, soluciones de código o reflexiones que no deben perderse.

⚡ Auto-Sync Vivo

Sincroniza tus notas en segundo plano 5 segundos después de que la IA termina de responder sin duplicar archivos.

📁 Carpetas Personalizadas

Elige exactamente en qué subcarpeta de tu Obsidian (ej: 5_Conversaciones) quieres guardar tus notas.

💎 Tipografía Pareja (H4)

Mapeo inteligente de encabezados para que el texto de la IA coincida en tamaño con tus propias preguntas.

📥 2. Métodos de Instalación en el Navegador

GemiMd se puede instalar en cualquier navegador basado en Chromium (Chrome, Brave, Edge, Opera) utilizando cualquiera de las dos vías siguientes:

🌐 Método A: Chrome Web Store (1-Clic Oficial)

La forma más rápida y recomendada para la gran mayoría de los usuarios.

  1. Visita la página oficial de GemiMd Exporter en la Chrome Web Store.
  2. Haz clic en el botón azul "Añadir a Chrome" (Add to Chrome).
  3. Confirma los permisos del navegador. ¡La extensión se instalará automáticamente sin necesidad de descargar archivos manuales!

💻 Método B: Modo Desarrollador (Carga Local / GitHub)

Para desarrolladores que descargan el código fuente desde GitHub o repositorio local.

  1. Abre tu navegador y entra a chrome://extensions/
  2. Activa el interruptor Modo de desarrollador en la esquina superior derecha.
  3. Haz clic en Cargar descomprimida (Load unpacked) y selecciona la carpeta del proyecto GEMIMD.
📌
Fijar en la barra superior: Independientemente del método elegido, haz clic en el icono azul del rompecabezas 🧩 en la esquina superior derecha del navegador y presiona el pin 📌 junto a GemiMd Exporter para tener el logo neón morado siempre a la vista.

⚙️ 3. Configuración de Obsidian Local REST API

Para lograr la sincronización sin clics directa hacia tu Obsidian, sigue estos sencillos pasos dentro de tu bóveda:

1 En Obsidian, abre Ajustes ⚙️ ➔ Plugins de la Comunidad (Community Plugins).

2 Busca e instala el plugin Local REST API.

3 En la configuración del plugin, asegúrate de activar el Servidor HTTP (Puerto 27123).

4 Copia la API Key / Bearer Token que te genera el plugin.

5 Abre el Popup de GemiMd en tu navegador, activa ⚡ Auto-Sync Vivo y pega tu API Key en el campo de texto.

Ejemplo de API Key: 80f41416c8ea9c51d835ef943352eeed611c59fbefc86d6071497500ce096b6e

⚡ 4. Los 4 Modos de Exportación

GemiMd te da flexibilidad absoluta para manejar tus notas según tus necesidades:

  1. ⚡ Sincronización Manual Inmediata: Al presionar el botón ⚡ Sincronizar en 5_Conversaciones, se envía la conversación actual instantáneamente a Obsidian.
  2. 💾 Descargar .md: Descarga directamente el archivo Markdown formateado a tu carpeta de Descargas de Windows.
  3. 📋 Copiar MD: Copia todo el contenido con metadatos en YAML Frontmatter al portapapeles.
  4. 🔮 Abrir en Obsidian (URI Protocol): Invoca el protocolo obsidian://new para abrir la nota de inmediato en Obsidian.

🛠️ 6. Solución de Problemas (Troubleshooting)

❌ El botón dice "Revisa la API Key u Obsidian":

Verifica que Obsidian esté abierto y que el puerto HTTP `27123` esté activo en la configuración del plugin Local REST API.

🧩 Sale una pieza azul en vez del logo neón:

Asegúrate de haber presionado el botón Recargar 🔄 en chrome://extensions/ para que Chrome registre los nuevos iconos redimensionados.
