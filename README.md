# GemiMD 🚀

**GemiMD** es una extensión moderna para Google Chrome que permite capturar, exportar y convertir contenido web y conversaciones de Google Gemini a formato Markdown enriquecido de manera rápida y elegante.

## ✨ Características Principales

- **Fácil conversión a Markdown**: Exporta contenido web con un solo clic.
- **Integración con Gemini**: Captura respuestas y conversaciones de Google Gemini manteniendo el formato.
- **Interfaz Moderna**: Popup intuitivo con diseño limpio y micro-interacciones.
- **Exportación Versátil**: Descarga archivos `.md` o copia el contenido directamente al portapapeles.

## 📁 Estructura del Proyecto

- `manifest.json`: Configuración de la extensión (Manifest V3).
- `background.js`: Scripts de segundo plano y escucha de eventos.
- `content.js`: Inyección y lectura del DOM en las páginas objetivo.
- `popup.html`, `popup.css`, `popup.js`: Interfaz principal de la extensión.
- `guia_desarrollo_extensiones.html`: Documentación interna para desarrolladores.
- `manual_usuario.html`: Manual de ayuda para los usuarios.
- `landing_presentacion.html`: Landing page de presentación.
- `assets/`: Íconos y logotipos de la extensión.

## 🚀 Instalación en Modo Desarrollador (Chrome)

1. Clona este repositorio o descarga el código fuente.
2. Abre Chrome y navega a `chrome://extensions/`.
3. Activa el **Modo de desarrollador** (esquina superior derecha).
4. Haz clic en **Cargar descomprimida** (*Load unpacked*).
5. Selecciona la carpeta de este proyecto.
